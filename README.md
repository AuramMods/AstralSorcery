# Astral Sorcery

Astral Sorcery is a magic mod for [Minecraft NeoForge](https://neoforged.net/) 
focused around harnessing the powers of starlight and the constellations.

## Building locally

Run builds and checks on the local machine with its Gradle cache. Keep
GitHub Actions out of the build and release process. Use JDK 21 and the
checked-in Gradle wrapper.

```sh
./gradlew build
```

Use the locally built jar from `build/libs/` when publishing a release.
